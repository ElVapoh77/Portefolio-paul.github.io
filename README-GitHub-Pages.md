## Mise en ligne sur GitHub Pages
1. Crée un dépôt GitHub.
2. Envoie tout le contenu du dossier dans le dépôt.
3. Va dans **Settings > Pages**.
4. Choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/ (root)`.
6. Enregistre.

## Vérification après publication
- teste le bouton LinkedIn
- teste les boutons **Me contacter** et **Demander mon CV**
- envoie un message test via le formulaire
- vérifie que la redirection vers `thank-you.html` fonctionne bien

## Conseil
Garde ton CV hors du dépôt GitHub si tu ne veux pas le rendre public.
Le formulaire sert uniquement à recevoir les demandes, puis tu envoies ton CV manuellement si tu le souhaites.
